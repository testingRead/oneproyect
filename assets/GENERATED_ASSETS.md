# Generated visual assets

These assets were generated specifically for OneProyect and then compressed on
the Android development device. They contain no third-party game resources.

## `loading_arena.webp` and `boot_splash.png`

Generated with OpenAI image generation in built-in/default mode.

Prompt summary: a 16:9 cinematic, realistic-stylized compact industrial
survival arena at dusk, orange and cyan lighting, light fog and a distant
meteor, with no people, text, logos or user interface.

- `loading_arena.webp`: 1280×720 WebP, quality 62, used by the in-game loading
  screen.
- `boot_splash.png`: 640×360 optimized PNG, used only because Godot's boot
  splash accepts PNG.

## `textures/industrial_floor.webp`

Generated with OpenAI image generation in built-in/default mode.

Prompt summary: a seamless square industrial concrete floor for a mobile 3D
game, subtle cool-gray slabs, restrained orange markings, realistic but clean,
flat-lit, with no text, objects or perspective.

The source was resized to 512×512 and encoded as WebP at quality 68. Godot
generates mipmaps for stable rendering at distance.
