# Fuente de interfaz

`RussoOne-Regular.ttf` procede del repositorio oficial de Google Fonts y se
distribuye bajo SIL Open Font License 1.1. La licencia íntegra está incluida en
`OFL-RussoOne.txt`.

La interfaz carga un único archivo de 39 KB para títulos, botones y etiquetas,
evitando familias o pesos duplicados.
